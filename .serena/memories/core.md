# Core

- Project: `bwatch`, VSCode extension for Bilibili live room monitoring.
- Root: `D:\self-work\bwatch` on Windows.
- PRD-first workflow is mandatory for non-trivial changes; start from `docs/prd/README.md` and project `prd-keeper` instructions.
- Main source map: `src/` extension host code, `media/` webview assets, `docs/prd/` product docs and PRD logs.
- Read `mem:tech_stack` for build/test stack, `mem:conventions` for code/doc conventions, `mem:suggested_commands` for useful commands, and `mem:task_completion` before finishing coding tasks.
