# 2026-09-09 场次峰值时段分类着色

### 编写人

dumpling

### 请求

在单主播场次峰值走势图中增加可持久化的时段着色开关，按直播主要时间段区分各场次点，同时保留现有折线、范围、高度和历史定位行为。

### 影响模块

- `media/webview.js`：本机时区时段分类、开关状态、点位着色、图例和悬浮详情。
- `media/webview.css`：分类图例与选中点外圈样式。
- `src/test/webviewRuntime.test.ts`：分类边界、跨午夜、并列规则、四小时阈值及 UI 契约。
- 直播监控 PRD、架构说明、产品概览和根 README。

### 代码变更

- 增加八个顺序时段和灰色长场次定义；短于四小时的场次按与各时段的最长重叠归类，跨午夜逐自然日累计。
- 最长重叠并列时使用直播中点分类，半开区间保证边界归入后一时段；四小时及以上场次直接归为长场次。
- 场次峰值标题栏增加默认关闭的“时段着色”按钮，通过 Webview state 持久化。
- 启用后仅数据点使用分类颜色，折线保持蓝色；选中点保留分类填充并使用更大尺寸和强调外圈。
- 图下按时间顺序显示九类图例，悬浮详情始终显示场次分类。

### PRD 更新

- 更新 `docs/prd/modules/live-monitor.md`、`docs/prd/architecture.md`、`docs/prd/product-overview.md`、`docs/prd/README.md` 和根 `README.md`。
- 明确时段边界、最长重叠、跨午夜、并列中点、四小时阈值、默认关闭及不修改宿主接口和历史格式的边界。
