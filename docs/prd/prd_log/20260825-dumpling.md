# 20260825 场次峰值分析

### 编写人

dumpling
### 请求

根据 VS Code 历史走势模块的新增场次信息分析，网页端同步实现相同的场次峰值图和交互逻辑。
### 影响模块

远程历史走势页面、页面运行时测试、历史网页 PRD。
### 代码变更
  - 增加场次峰值分析区，默认最近 30 场，支持最近 10 场、最近 30 场和全部。
  - 复用导出的 sessions 数据，使用 180px 高度 SVG 图表、自适应纵轴、稳定排序和点位高亮。
  - 悬浮显示完整起止时间、峰值在线人数和直播时长；点击或键盘确认点位调用既有场次定位逻辑。
  - 将 sessionPeakRange 写入 localStorage，支持加载、空数据和错误状态。
  - 增加夜间主题下的峰值图样式，并保持 360px 最小图表宽度。
### PRD 更新
在 docs/prd/modules/history-site.md 补充场次峰值分析的展示、范围、点位交互、持久化和数据边界。
### 验证
运行 node --check site/app.js、npm test、数据校验和 PRD 校验。
### 风险/后续事项
场次摘要仍依赖插件导出后手动提交；网页只显示最近一次推送的静态快照，无法提供实时场次数据。
