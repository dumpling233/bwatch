# PRD 变更日志 - 2026-08-14

## 筛选范围标签显示开播人数

### 编写人

dumpling

### 请求

总览和历史走势图的筛选分组标签需要显示该范围的实际开播人数和总人数，格式为 `a/b`；修复插件跨本地自然日持续运行后历史日期组件不更新的问题；统一总览与历史走势的排版和宽度自适应行为；支持调整自定义分组顺序。

### 影响模块

- 总览走势图。
- 历史走势图。
- 内置范围和自定义分组范围标签。
- 历史日期列表和日历选择组件。
- 总览与历史走势图顶部控制区、图表容器和图例布局。
- 自定义分组管理、配置持久化及各分组展示入口。

### 代码变更

- 范围标签按自身实际筛选结果计算 `当前开播人数/范围总人数`。
- 筛选标签与合计曲线复用同一计数格式，避免成员口径不一致。
- 增加 Webview 运行时测试，验证有数据范围使用过滤后的实际人数。
- Webview 在历史面板展开期间按已完成快照的本地自然日检测跨日，并仅在跨日后的首轮采样完成时重新加载历史日期列表。
- 日期列表刷新保留仍有效的当前日期及时间范围；增加跨日、同日和面板收起场景的运行时回归测试。
- 总览与历史走势统一为标题、筛选范围、日期/时间范围纵向排列，两个时间条各自独占一行；历史日期输入与快捷日期按钮组成可换行的独立控制区。
- 面板、图表和图例补齐可用宽度约束，历史图与总览图统一按容器实际像素宽度重绘 SVG，避免多图例撑出异常横向滚动。
- 分组管理行增加上移、下移按钮，扩展宿主交换相邻分组并写回 `bwatch.groups`；主列表、总览筛选和历史筛选随配置顺序同步更新。
- 增加分组重排单元测试，覆盖上移、下移、首尾边界和不存在分组，且不修改输入数组。

### PRD 更新

已同步产品概览、直播监控模块和 Webview 架构说明，并补充历史日期跨日自动更新规则。

### 风险/后续事项

历史范围标签的开播人数表示当前快照状态；历史数据加载前显示 `0/0`。新日期会在跨日后的首个监控快照完成并写入采样后进入日期列表；历史面板收起期间不扫描日期文件，重新展开时会正常加载最新列表。
