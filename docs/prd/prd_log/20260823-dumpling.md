# 2026-08-23 PRD 变更日志

## 远程历史走势页面

### 编写人

dumpling

### 请求

将 VSCode 插件本地长期在线人数历史手动导出到 GitHub 仓库，并通过公开 GitHub Pages 提供完整的历史走势查看工作台，不引入后端服务或自动 Git 操作。

### 影响模块

- `src/` 与 `package.json`：导出契约、命令注册和自动化测试。
- `site/`、`scripts/` 与 `.github/`：静态工作台、数据校验和 Pages 部署。
- `docs/prd/`、README 与项目地图：产品、架构、模块和操作说明。

### 代码变更

- 新增命令 `bwatch.exportHistorySiteData`，首次选择仓库根目录并在本机 `globalState` 记忆路径；路径失效时可重新选择。
- 新增 `schemaVersion: 1` 静态导出契约：Manifest、按本地自然日拆分的原始采样、按房间拆分的场次摘要。
- 导出包含已移出监控列表的长期历史，保留毫秒时间戳和 `null`；稳定排序、跳过未变化文件并最后原子更新 Manifest。
- 新增无构建依赖的 `site/` 历史工作台，支持相邻双日、分钟范围、主播/场次定位、多范围合计、图例显隐、SVG 悬浮读数、图表高度和 `localStorage` 状态。
- 新增数据结构校验脚本和 GitHub Pages 工作流；工作流只在默认分支 push 或手动触发时部署。
- 导出命令不会执行 Git 操作，也不会导出 Cookie、Token、代理配置或其他 VSCode 状态。

### 测试

- 新增导出测试，覆盖毫秒时间戳、`null`、午夜拆分、已删除房间、历史主播名、场次一致性和重复导出确定性。
- 页面发布前校验覆盖 Manifest、日期文件、场次文件、稳定排序、引用路径、时间边界与采样值。

- 同步 PRD 总入口、产品概览、架构、模块索引、项目地图和 README。

### 风险/后续事项

- GitHub Pages 和导出数据公开可下载，首次推送前需要确认房间号、主播名、分组、采样时间与在线人数允许公开。
- 15 秒原始采样会持续增加仓库体积；按日分片减少旧数据重写，但不消除长期增长。
- Pages 线上工作流与最终 URL 只有在用户手动提交并推送默认分支后才能确认，本次实现不自动执行 Git 操作。
