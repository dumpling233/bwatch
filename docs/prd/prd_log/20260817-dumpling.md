# 历史走势渲染失败排查与修复

### 编写人

dumpling

### 请求

排查切换历史日期后出现“历史走势渲染失败”的问题，避免历史面板因本地数据异常而空白。

### 影响模块

- `media/webview.js` 历史数据接收、归一化和历史走势图渲染。
- 历史走势运行时回归测试。

### 代码变更

- 历史查询消息进入 Webview 后统一归一化日期、起止时间、房间号、主播名和采样点。
- 过滤无效房间、非法时间戳和非法在线人数；同一时间戳保留最后一条有效记录并按时间排序。
- 历史图构造过程增加房间数组和时间窗口兜底；渲染异常提示保留具体错误信息，避免单条异常数据导致整个面板不可诊断。
- 选择历史日期时自动保证历史走势内容处于展开状态，避免加载期间出现面板状态错觉。

### PRD 更新

- 已更新 `docs/prd/modules/live-monitor.md`、`docs/prd/architecture.md` 和 `docs/prd/product-overview.md`，记录历史查询结果归一化和渲染容错规则。

### 风险/后续事项

# 聚合走势图自适应坐标刻度

### 编写人

dumpling

### 请求

在可调图表高度基础上，根据走势图当前宽度和高度显示更多易读的横纵轴位置数字。

### 影响模块

- 总览与历史聚合 SVG 坐标轴、网格线和纵轴范围。
- 宽高响应式图表运行时测试。

### 代码变更

- 横轴根据绘图区宽度从整分钟和整小时步长中选择刻度，宽图增加刻度、窄图减少刻度。
- 纵轴从 `0` 到实际最大值之间按 `1/2/5 × 10^n` 生成易读刻度，高图增加刻度、矮图减少刻度。
- 刻度和网格线使用同一坐标；内部刻度与端点过近时按最小像素间距自动移除，避免文字重叠。
- 移除原先没有数字对应关系的固定比例横向网格线。

### PRD 更新

- 已同步产品概览、直播监控模块、架构文档和 README。

### 验证

- `node --check media\\webview.js`
- `npm.cmd test`：71 项测试全部通过。
- `python .agent\\skills\\prd-keeper\\scripts\\check_prd_keeper.py --log-file docs\\prd\\prd_log\\20260817-dumpling.md`
- `npx.cmd vsce package --out bwatch-0.1.0.vsix`

### 风险/后续事项
